# 弈仙牌助手：已验证数值规则云源

本仓库存放公开牌效资料、受控数值模板和公告监测脚本。助手游戏操作源码、账号信息与实战日志不在本仓库。

初始规则基于 2026 年 10 月 8 日官方公告。首批注册 54 个准确原生牌面：该公告的 45 个牌面及 9 个已经核验的普通固定攻击牌面。相同原生 ID、等级和已支持效果模板中的数字变化可生成数据更新；新增效果、未注册模板、含糊公告和未核验费用变化会标记待适配。

GitHub Actions 每 5 分钟检查官方 Steam 公告和注册的 Wiki 页面。平台调度可能延迟。只有完整数据候选通过协议校验才会更新 `public/manifest.json`，否则保留上次已验证规则，并写入 `public/monitor_status.json`。

助手从 HTTPS 云源读取清单、校验模板与内容哈希，在后台准备更新，并在下一局固定一份不可变规则快照。已开始的对局不会混用规则。接收端最低版本为 1.1.283；1.1.282 尚不具备完整的云数值接收功能。

公开规则入口：`public/manifest.json`。当前工作流只发布数据，不执行公告中的文字或下载外部代码。

复杂仙命机制、未注册卡牌与游戏客户端修复仍需要对应引擎版本核验。监测到公告不等于该公告全部已适配。

1.1.299 新增 `numeric-templates-2`：狂雷电闪三个等级兼容“其他雷牌”文案；冥灵血影步三个等级按新版先回血、再加内伤并计算身法的顺序执行。新旧文案的数字按具体效果映射，后续同一已核验模板的数字变化会由现有工作流自动发布，助手后台下载、下局固定应用。身份、等级、费用和未知机制仍严格核验；旧助手保留旧包并提示升级。六项适配不会使未注册的卡牌自动获得模拟支持。

1.1.285 起，助手的更新公告页面显示 GitHub 连通状态、已核验规则版本、上游检查时间及待适配项。清单也公布 `monitor_state`、`source_errors` 和 `supported_faces`；资料源异常或检查记录过期时，助手继续使用已核验规则，并明确标示状态。数值规则云更新与助手程序更新分别进行。

1.1.329 新增 numeric-templates-3 与 2026.10.15.4 规则，注册78个准确原生等级牌面，覆盖10月15日10项卡牌调整。旧54面协议仍可验证已固定历史快照；新包必须78面齐全且助手至少1.1.329。回响阵纹当前客户端代码仅回血，文案与增加上限的实现不一致；公开规则包附带client_notes明确说明，模拟器按该客户端静态实现处理。御风飞闪先整数除2，再在玩家境界达到化神时翻倍。新机制和费用变更仍需人工适配，监测器不执行远端代码。

云端公告复核修复（2026-10-15）：官方编辑已适配公告后，监测器以准确来源、完整平衡调整段和30个原生牌面的身份、费用及参数重新核验。调整段及牌面仍相同时只更新复核记录，不改变规则版本或数值；新的数值、费用、机制、重复标题及调整段外的已注册卡牌变更继续待适配。通用解析同时区分燃烬灭固定生命削减与旧的加攻系数，并以段落边界隔开逐尘步和后续卡牌。助手1.1.330无需重装。
