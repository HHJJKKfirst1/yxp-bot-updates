# 弈仙牌助手：已验证数值规则云源

本仓库存放公开牌效资料、受控数值模板和公告监测脚本。助手游戏操作源码、账号信息与实战日志不在本仓库。

初始规则基于 2026 年 10 月 8 日官方公告。首批注册 54 个准确原生牌面：该公告的 45 个牌面及 9 个已经核验的普通固定攻击牌面。相同原生 ID、等级和已支持效果模板中的数字变化可生成数据更新；新增效果、未注册模板、含糊公告和未核验费用变化会标记待适配。

GitHub Actions 每 5 分钟检查官方 Steam 公告和注册的 Wiki 页面。平台调度可能延迟。只有完整数据候选通过协议校验才会更新 `public/manifest.json`，否则保留上次已验证规则，并写入 `public/monitor_status.json`。

助手从 HTTPS 云源读取清单、校验模板与内容哈希，在后台准备更新，并在下一局固定一份不可变规则快照。已开始的对局不会混用规则。接收端最低版本为 1.1.283；1.1.282 尚不具备完整的云数值接收功能。

公开规则入口：`public/manifest.json`。当前工作流只发布数据，不执行公告中的文字或下载外部代码。

复杂仙命机制、未注册卡牌与游戏客户端修复仍需要对应引擎版本核验。监测到公告不等于该公告全部已适配。
